**SIDUS: образовательные калькуляторы космической инженерии**

Я инженер-программист, не космический инженер, но космическая инженерия мне интересна. Поэтому я сделал sidus.tools.

SIDUS — бесплатный открытый набор образовательных калькуляторов: орбитальная механика, propulsion, спутниковые операции, RF, ECLSS. Около 175 инструментов. Чистый SI. MIT. В браузере. Без аккаунта.

Смысл — быстрая SI-проверка, которую видно: входы, формула, результат, GitHub Edit. Модели нарочно небольшие.

Тот же каталог на публичном MCP: https://sidus.tools/api/mcp (Streamable HTTP). Клиент смотрит на URL, репозиторий клонировать не нужно. Agent Skill: `npx skills add massimodeluisa/sidus-tools --skill sidus`.

Формулы и экспортируемый код нужно проверять и тестировать.
