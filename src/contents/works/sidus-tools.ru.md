**SIDUS: образовательные калькуляторы космической инженерии**

Я пишу софт и не космический инженер. Я опубликовал [sidus.tools](https://sidus.tools), чтобы эти проверки жили в SI, на странице, которую можно прочитать, и на протоколе, который клиент бьёт без второй физической библиотеки, тихо уезжающей в сторону.

SIDUS (*sidus*, латынь: созвездие) — бесплатный открытый набор образовательных калькуляторов: орбитальная механика, propulsion, спутниковые операции, RF, ECLSS. 201 инструмент на 4 сентября 2026. Чистый SI. MIT. В браузере. Без аккаунта. Независимый проект, без аффилиации с агентствами.

Смысл — быстрая SI-проверка, которую видно: входы, формула, результат, GitHub Edit. Дефолты образовательные, WGS-84-класса (μ⊕ = 3.986004418×10¹⁴ m³/s², экваториальный радиус 6 378 137 m). Модели нарочно небольшие.

Рядом с Hohmann — Lambert, SGP4, живой орбитальный вид, Tsiolkovsky, RF link budget, атмосфера кабины и porkchop Earth–Mars.

Тот же каталог на публичном MCP: https://sidus.tools/api/mcp (Streamable HTTP). Клиент смотрит на URL, репозиторий клонировать не нужно. Agent Skill: `npx skills add massimodeluisa/sidus-tools --skill sidus`.

Формулы и экспортируемый код нужно проверять и тестировать.
