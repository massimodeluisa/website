[isready.ai](https://isready.ai) отвечает на один вопрос. Когда GPTBot, ClaudeBot, PerplexityBot или OAI-SearchBot забирают страницу, получают ли они статью?

Chrome выполняет JavaScript. Эти обычно нет. Приложение на React или Vue может выглядеть готовым в браузере и всё равно отдать пустой документ, а страница-проверка может убрать тебя из ответов, не трогая обычную выдачу. isready.ai — продукт Smart Squad из Удине. Он забирает страницу так, как это делают те боты, и прогоняет 32 проверки. Каждая находка говорит, что увидено, чем это обходится и что менять. Оценка версионируется, от 0 до 100. Проверки содержания идут по Aggarwal et al., GEO, KDD 2024: цитаты, статистика, ссылки на источники. Файл llms.txt отмечается и никогда не двигает оценку.

```bash
npx isreadyai yourdomain.com --deep --md
```

Эта команда и Markdown, который она пишет, бесплатны. Скан можно запустить и с сайта, без аккаунта. GitHub Action может уронить сборку, когда оценка падает. Второй проход может оценить, видит ли агент с браузером содержание и элементы управления.

Pro стоит €19 в месяц, Team €49. Туда входят наблюдение, история, бейдж, Ask-your-site и pull request с правками. Сканер открытый. Платишь за хостинг дашборда.
