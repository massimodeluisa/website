**SIDUS: освітні калькулятори космічної інженерії**

Я інженер-програміст, не космічний інженер, але космічна інженерія мені цікава. Тому я зробив sidus.tools.

SIDUS — безкоштовний відкритий набір освітніх калькуляторів: орбітальна механіка, propulsion, супутникові операції, RF, ECLSS. Близько 175 інструментів. Чистий SI. MIT. У браузері. Без акаунта.

Сенс — швидка SI-перевірка, яку видно: входи, формула, результат, GitHub Edit. Моделі навмисно невеликі.

Той самий каталог на публічному MCP: https://sidus.tools/api/mcp (Streamable HTTP). Клієнт дивиться на URL, репозиторій клонувати не треба. Agent Skill: `npx skills add massimodeluisa/sidus-tools --skill sidus`.

Формули й експортований код треба перевіряти й тестувати.
